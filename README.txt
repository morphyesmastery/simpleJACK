TROUBLESHOOTING — THE 4 THINGS THAT CAN GO WRONG
────────────────────────────────────────────────────
1. "Nothing happened when I double-clicked the .bat"
   → Your browser blocked the popup. Just open your
     browser and go to:  http://127.0.0.1:8797

2. "It says key invalid / 401"
   → You copied extra spaces or missed characters.
     Copy the whole key again. They're long — that's normal.

3. "It's slow / thinking a long time"
   → First answer on a local model loads it into memory.
     The second answer is fast. Give the first one a minute.

4. "Antivirus deleted / quarantined a file"
   → Restore it and add the folder to exclusions.
     Portable Python triggers false positives. It's yours.

STILL STUCK?
